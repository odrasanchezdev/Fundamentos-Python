## Instalación y uso 🚀
Este repositorio contiene ejercicios pensados para que puedas aprender Python desde cero. La idea es que intentes resolver los ejercicios por tu cuenta antes de revisar las soluciones. Todo está organizado para que puedas avanzar paso a paso, incluso si es tu primera vez programando.

**Cómo empezar (recomendado para principiantes)**
1. Entra a la carpeta del ejercicio que te interese.
2. Lee las instrucciones con calma.
3. Abre tu editor favorito (puede ser VS Code, PyCharm o incluso el bloc de notas).
4. Crea un archivo nuevo con terminación `.py`.
5. Intenta escribir tu propia solución. No importa si no sale a la primera: forma parte del proceso de aprender.
6. Cuando termines o ya no sepas cómo continuar, revisa el archivo de solución incluido para comparar y aprender nuevas formas de resolverlo.
<br>
<br>

**Qué necesitas para ejecutar los ejercicios**

Para usar los ejercicios, solo necesitas:
- Python 3 instalado en tu computadora.
- Un editor de texto o IDE para escribir el código. Cualquier opción sirve:
  - Visual Studio Code
  - PyCharm
  - IDLE (viene con Python)
  - Bloc de notas o cualquier editor básico

Para ejecutar un archivo `.py`, abre tu terminal y escribe:
`python nombre_del_archivo.py`
<br>
<br>

**Cómo descargar el repositorio**

No necesitas instalar nada complicado. Puedes obtener el repositorio de dos formas:
1. Clonar el repositorio con Git (Si cuentas con experiencia): `git clone https://github.com/odrasanchezdev/python-fundamentos-didacticos`
2. Descargar el ZIP desde GitHub: En esta página principal, busca el botón azul `Code` y despliega el menú. Da clic en el botón“Download ZIP” y descomprímelo en tu equipo.
3. No te preocupes, puedes copiar y pegar directamente el ejercicio en tu editor. Si recién incias tu camino en la programación.
<br>
<br>

**Qué hacer después de descargarlo**
1. Abre la carpeta del ejercicio.
2. Lee primero las instrucciones antes de ver la solución.
3. Ejecuta el archivo `.py` para probar la solución.
